# RePrint — Documentation

This folder gathers quality, setup, and testing documentation for the RePrint e-commerce frontend.

## Contents

| File | Description |
|------|-------------|
| [TEST_REPORT.md](./TEST_REPORT.md) | Automated test-run results, coverage summary and list of what was tested. |
| [TESTING_SETUP.md](./TESTING_SETUP.md) | How the Vitest test suite is configured and how to run it. |
| [FRONTEND_ARCHITECTURE.md](./FRONTEND_ARCHITECTURE.md) | High-level overview of the Vue 3 application structure. |

> Full interactive coverage report is generated into `coverage/` (git-ignored) by running `npm run test:coverage`.
